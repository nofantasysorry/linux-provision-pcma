# CLAUDE.md

Инструкции для AI-агентов, работающих с этим репозиторем.

## Что это за проект

`provision.sh` — единый bash-скрипт подготовки заводского терминала ввода данных под Linux Mint 21.3 «Virginia» (Cinnamon) для работы 24/7. Репозиторий публичный, история переписана — не пытайтесь «восстановить» старые коммиты.

## Ключевые факты

- Целевая ОС: Linux Mint 21.3, Cinnamon, LightDM, systemd. Терминалы заводские, работают 24/7.
- Основной браузер — Firefox (автозапуск через `/etc/xdg/autostart`), резервный — Google Chrome (устанавливается из официального репозитория, готов к запуску ярлыком).
- Пользователи: `administrator` (создан при установке Mint, в группе sudo) и `pcma` (создаётся скриптом: без пароля, без sudo, автологин через LightDM).
- Автообновления **намеренно отключены** (apt-таймеры, unattended-upgrades). Ручные `sudo apt update && sudo apt full-upgrade` должны продолжать работать — не ломайте это.
- Сон, гибернация, гашение и блокировка экрана запрещены (`systemctl mask` + gsettings).
- Сертификаты PCMA (Root CA + Sub CA) ставятся в три хранилища: системное (`update-ca-certificates`), политики Firefox, NSS Chrome. Сами `.crt` лежат в `certificates/`.
- `START_URL = http://mainpage.pcmarus.loc/` — внутренняя страница завода.
- Conky с автоопределением сетевого интерфейса (не зашивайте `eno1`).

## Архитектура скрипта

- `set -Eeuo pipefail`, `trap ERR`, umask 022. Всё на русском: сообщения, логи, комментарии.
- Два режима вывода: тихий по умолчанию (полоса прогресса `[N/14]`, спиннер для долгих шагов, `✓`/`✗`) и подробный с `-v`/`--verbose`. Справка: `-h`/`--help`.
- Каждый шаг выполняется через `run_step <title> <long|short> <function>`: вывод шага перенаправляется в `provision.log`, спиннер — фоновый подпроцесс, гасится в `stop_spinner`.
- Скрипт **идемпотентен**: повторный запуск безопасен (сертификаты NSS удаляются и добавляются заново, конфиги перезаписываются). Любое новое изменение обязано сохранять идемпотентность.
- Ошибки: `die` — фатальная, `warning` — мягкая (шаг продолжается). Предпочитайте мягкие предупреждения для нефатальных сбоев.
- Шаги вызываются в `main()` по порядку; составные шаги (напр. `create_pcma_user_full`) объявлены **до** `main` — bash требует определения функции до вызова.

## Правила изменений

1. Проверяйте синтаксис после каждой правки: `bash -n provision.sh`.
2. Концы строк — только LF (см. `.gitattributes`). Коммиты от `nofantasysorry <nofantasysorry@users.noreply.github.com>`.
3. Не добавляйте в репозиторий личные данные (ФИО и т.п.) — они были намеренно удалены при подготовке к публикации.
4. Не включайте автообновления, не ставьте watchdog/демонов без запроса — пользователь явно отклонял.
5. Новые файлы конфигурации кладите в `/usr/local/share/pcma/`, автозапуски — в `/etc/xdg/autostart/pcmarus-*.desktop` с `OnlyShowIn=X-Cinnamon;`.
6. Обновляйте `README.md` (RU + EN, обе части зеркальны) при любом изменении поведения скрипта.
